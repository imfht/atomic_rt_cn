关于本项目

项目简介

Atomic Red Team CN 是一个基于 Atomic Red Team 的中文攻击技术数据库和分析平台。

主要功能

  • 📊 攻击技术数据库：存储和管理来自 Atomic Red Team 的攻击技术
  • 🔄 数据同步：从官方仓库同步最新的攻击技术数据
  • 🤖 智能分析：使用大语言模型对攻击技术进行中文分析和总结
  • 🔍 搜索功能：快速查找特定的攻击技术
  • 📈 统计展示：可视化展示数据库统计信息

技术栈

  • 后端：Python Flask + SQLAlchemy
  • 前端：HTML + CSS + JavaScript
  • 数据库：SQLite
  • AI集成：OpenAI API (或兼容接口)
